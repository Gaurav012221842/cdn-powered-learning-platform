# Cloudflare R2 Bucket Configuration

Cloudflare R2 is used as zero-egress S3-compatible object storage.

## Bucket Structure
- `/raw/` - Raw uploaded user videos & PDFs before processing.
- `/hls/` - Segmented HLS `.m3u8` playlists and `.ts` video chunks.
- `/images/` - Optimized course thumbnails and user profile pictures.
- `/certificates/` - Generated PDF completion certificates.
